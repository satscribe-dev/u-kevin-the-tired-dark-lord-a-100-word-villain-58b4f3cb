A program that writes one 100-word monologue for a fantasy villain who is
secretly just very tired — the Dark Lord himself, forty years into the job,
doing the voice, and filing a formal complaint with his knees.

Run it with Node 22:

```sh
node main.ts
```

It writes the monologue to `/output/entry.txt` — exactly 100 words,
543 characters, deterministically (two runs are byte-identical).
